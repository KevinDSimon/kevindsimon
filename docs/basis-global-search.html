Global Search

Centro

Goal

Add Global Search to Basis, giving users a quick way to find content, move between views, and take common actions from anywhere in the platform.

Value

Basis spans several roles and functions within adtech, and users managing multiple campaigns found its complex hierarchy painful to navigate. A dynamic global search lets them comb through unstructured data and quickly find what they want, when they need it most.

My role

I was the UI designer, working very closely with a UX designer, product, and engineering.
